
# HTTP Module

It is built in Node.js Module which allows developers to create web server and web client without installing any external package.
one of the most important module in Node.js, originally designed for building
scalable network application and web servers.

1. create web servers
2. handle client request
3. Build Rest APIs
4. Non-Blocking I/O
5. Foundation of Express.js

## http status codes

- 200 -> Ok
- 201 -> Created
- 400 -> Bad Request
- 401 -> Unautharized
- 403 -> forbidden
- 404 -> Not Found
- 500 -> Internal Server Error

server can send to the client 
1. html content
2. html file
3. json data
4. plain file
5. js file 
6. any file to download
7.etc
